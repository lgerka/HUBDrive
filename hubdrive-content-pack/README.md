# HUBDrive Content Pack

Готовый комплект для главной страницы и раздела новостей.

## Структура

- `banners/` — три баннера верхнего слайдера, 1600×800.
- `news/cards/` — обложки карточек, 1200×800.
- `news/heroes/` — баннеры страниц материалов, 1600×900.
- `news/covers/` — исходные универсальные обложки, 1600×1000.
- `content.md` — тексты в удобном для согласования виде.
- `content.json` — те же данные в структурированном виде для импорта.

Все изображения в комплекте сохранены в `.webp` и оптимизированы для загрузки в приложение.

На всех изображениях отсутствуют встроенные заголовки. Метки и текст должны накладываться интерфейсом приложения. Для картинок используйте `object-fit: cover`.
